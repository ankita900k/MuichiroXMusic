MUICHIRO DEMON HUNT RPG — PATCH NOTES
======================================

This patch is applied on top of the uploaded MuichiroXMusic-main project.
It preserves the existing music system and the existing mystery-hunt game.

Files changed:
- bot.py: imports/registers the RPG handlers, initializes RPG tables during startup,
  adds RPG commands to Telegram's command menu, and adds an RPG help section.
- webhook.py: calls the application's post_init explicitly because this project
  starts python-telegram-bot manually in FastAPI/Render webhook mode; it also
  restores raid timeout watchers after PTB starts.
- demon_hunt_rpg.py: new, separate group raid RPG engine and UI.

Files intentionally not changed:
- demonslayer_hunt.py (the existing character mystery-hunt system)
- database.py (existing database schema and connections)
- music/ (all music and voice-chat files)
- Dockerfile, render.yaml, requirements.txt, and existing assets.

Render:
- Keep the existing Web Service / Docker setup.
- Keep your current environment variables, including BOT_TOKEN and DATABASE_URL.
- No new Python dependencies are required; the project already lists
  python-telegram-bot and psycopg2-binary.
- The RPG creates only rpg_* tables in the configured database. It uses the same
  DATABASE_URL as the bot, but its RPG coins are separate from legacy Slayer Points.
- Existing project artwork in assets/start and assets/demon_hunt is reused.

RPG commands:
- /launchhunt easy|normal|hard|upper|final — launch a group raid (group admins only)
- /raidstatus — inspect the current raid
- /breathing — choose or view a breathing style
- /rpgprofile — RPG EXP, Corps rank, coins, victories, and defeat progress
- /rpgstore — browse the separate RPG store
- /rpgbuy <item> — buy potion, whetstone, armor, katana, or charm
- /rpginventory — view RPG inventory
- /rpguse potion — use a potion for +80 damage on the next attack
- /rpgtrain <style> — unlock/equip a standard style for 100 RPG coins + 100 EXP
- /legendary sun|moon — choose a separate legendary path; eligible raid victories
  progress only the currently selected path, with 100 personal defeats required
- /rpgleaderboard — view RPG rankings
- /rpghelp — full RPG command list

Gameplay notes:
- All 12 standard styles are available for the first choice.
- One free correction is available after the initial style choice.
- Personal combat panels are sent by private chat; group raid status stays in the group.
- Attack buttons validate Telegram user ID, active raid status, and a short action cooldown.
- Only contributors who deal at least 1% of the demon's starting HP qualify for victory
  rewards and a personal demon defeat.
- A timed-out raid fails without victory rewards; participating attackers lose 10 RPG coins.
- Raid state, profiles, contributions, inventory, and path progress are stored in the
  configured database. Timeout watchers are restored on service startup.
